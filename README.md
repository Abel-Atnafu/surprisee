# Our Story 💕

A beautiful, interactive website celebrating our relationship. Built with React, Framer Motion, and TailwindCSS.

## Features

- **Hero Section**: Stunning landing with smooth animations
- **How We Met**: Visual storytelling of your connection through art
- **Timeline**: Interactive milestones with expandable details
- **First Date**: Beautiful memories of your cafe moment
- **Music Section**: Drake & PnD playlist with emotional integration
- **Interactive Elements**: Confetti effects, expandable cards, and hidden easter eggs
- **Responsive Design**: Beautiful on desktop and mobile

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Build for Production

```bash
npm run build
npm run preview
```

## Deployment

Deployed on Vercel for instant, global delivery.

```bash
npm i -g vercel
vercel
```

## Tech Stack

- **React 18** - UI framework
- **Vite** - Build tool
- **Framer Motion** - Animations
- **TailwindCSS** - Styling
- **Vercel** - Hosting
